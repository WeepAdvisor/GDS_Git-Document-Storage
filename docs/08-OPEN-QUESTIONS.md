## Решения владельца (2026-10-03)

### Q5 — аутентификация

В UI сразу оба входа, не «сначала PAT, Device Flow потом»:

- «Sign in with GitHub» — OAuth Device Flow, scope `repo`. Client ID владелец кладёт в `Config/Local.xcconfig` (`GITHUB_OAUTH_CLIENT_ID`). Client secret в приложении нет.
- «Use a token instead» — classic PAT (`repo`) или fine-grained (Contents: Read and write).
- Реализация протокола — фаза 1 (`DeviceFlowAuthenticator` + проверка PAT). Экраны — фаза 6 (Accounts + мастер Add Folder).
- При добавлении папки `CapabilityChecker` перебирает все аккаунты. Если ни один не даёт доступ — «Sign in with another GitHub account» прямо в шаге проверки.

### Q6 — масштаб

Подтверждено: документы и картинки, ≤ 5 000 файлов, файл ≤ 50 MB, ≤ 10 человек одновременно. Транспорт v1 — только GitHub API (ADR-002). Локальный `.git` / libgit2 не добавлять.
