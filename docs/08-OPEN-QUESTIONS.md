# 08 — Открытые вопросы и принятые допущения

Статусы: ❓ открыт, ✅ решён (ответ ниже), 🟡 принято допущение, можно пересмотреть.

| # | Вопрос | Статус | Текущее допущение |
|---|---|---|---|
| Q1 | Имя продукта и bundle id | ❓ | `GitDocumentStorage`, `com.nasonov.gitdocumentstorage` (плейсхолдер в `project.yml`) |
| Q2 | Какой Apple Team ID использовать? Есть ли платный Developer Program (нужен для Developer ID/нотаризации в фазе 8)? | ❓ | В системе найден действующий сертификат команды `<team-id>` (до 16.10.2026) и просроченный `<old-team-id>`. Для разработки хватит любого, Xcode перевыпустит сертификат при входе в аккаунт. |
| Q3 | Режим «не запущено → недоступно»: мягкий (`disconnect`, папка видна серой, кэш сохраняется) или строгий (`remove` домена, папка исчезает, кэш теряется)? | ❓ | Мягкий по умолчанию, строгий — опция (ADR-005) |
| Q4 | Политика конфликтов по умолчанию: `lastWriterWins` (как SMB; старая версия в истории git) или `keepBoth` (conflicted copy, как Dropbox)? | ❓ | `lastWriterWins` + уведомление проигравшему (ADR-006) |
| Q5 | Кто регистрирует OAuth App на GitHub (нужен Client ID; делается за 2 минуты в настройках аккаунта/организации)? Или начинать с PAT и добавить Device Flow позже? | ❓ | Device Flow в фазе 1, Client ID — от владельца |
| Q6 | Масштаб: типичный размер репозиториев (файлов / МБ), размеры файлов, сколько людей одновременно? Это определяет, достаточно ли API-транспорта (ADR-002) или нужен libgit2-бэкенд уже в v1 | ❓ | Документы/картинки, ≤ 5 000 файлов, ≤ 50 MB на файл, ≤ 10 человек |
| Q7 | Нужен ли выбор ветки при добавлении папки или всегда default branch? | ❓ | Default branch, селектор ветки показывается «под спойлером» |
| Q8 | Показывать ли dotfiles репозитория (`.gitignore`, `.github/`)? Finder прячет их по умолчанию | 🟡 | Отдаём всё, кроме `.git`; Finder прячет сам |
| Q9 | Нужны ли уведомления «@user изменил файл» (как в Dropbox)? | 🟡 | Фаза 9, выключено по умолчанию |
| Q10 | Нужна ли русская локализация UI в v1? | 🟡 | Нет; строки в `.xcstrings`, добавить легко |
| Q11 | Распространение: только DMG «для своих» или App Store? (App Store = sandbox уже есть, но Device Flow/`repo`-scope и File Provider требуют ревью) | 🟡 | DMG + нотаризация, без App Store |
| Q12 | Минимальная macOS | 🟡 | macOS 15 (Sequoia); у вас 26 |
| Q13 | Что делать с Git LFS-репозиториями: отказывать в добавлении или показывать pointer-файлы с предупреждением? | 🟡 | Предупреждение в «пинге», файлы-указатели показываем как есть |
| Q14 | Нужна ли «корзина» (восстановление удалённого из истории git прямо из меню)? | 🟡 | Нет в v1; история доступна на GitHub |
| Q15 | Office lock-файлы (`~$doc.docx`): игнорировать (чисто) или синхронизировать (другие видят «файл открыт», как на SMB)? | 🟡 | Игнорировать |
